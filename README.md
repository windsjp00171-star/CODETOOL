# CODETOOL

免費、在瀏覽器裡就能用的小工具。不用註冊、不用安裝，資料只存在使用者自己的瀏覽器。

## 工具

### [票券工作室](https://windsjp00171-star.github.io/CODETOOL/ticket-studio/)

製作摸彩券、號碼牌、入場券、餐券與名牌的編號印刷工具。

- 放上圖片、設定號碼範圍，自動排成 A4、A3、B4 或 Letter 的 PDF
- 「裁好疊起來就連號」排法：整疊一起裁、依序疊好就是連號
- 自動 3 mm 出血、Excel／CSV 名單套印、QR Code 與防偽驗證碼
- 「抽獎紀錄」：現場輸入或掃描抽出的號碼，自動擋下重複與作廢號碼，並可投影得獎號碼

## 使用提醒

- 列印 PDF 時選「實際大小／100%」，不要選「符合頁面」。
- 抽獎紀錄只存在當天那台電腦的瀏覽器，結束後請匯出 CSV 備份。
