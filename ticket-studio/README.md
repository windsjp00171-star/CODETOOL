# 票券工作室

摸彩券、號碼牌、入場券、餐券、名牌／座位卡的編號印刷工具，附現場抽獎登記與投影。

單一 HTML 檔、直接用瀏覽器開啟即可使用（首次開啟需要網路載入 jsPDF / JSZip，圖片本身不會上傳）。

## 功能
- 用途範本：摸彩券、號碼牌、入場券（QR＋防偽碼）、餐券／兌換券、名牌／座位卡，一鍵套用尺寸、欄位與拼版
- 資料來源：連續編號，或從 Excel 貼上／匯入 CSV 名單（每列印一張，欄位用 `{欄位名稱}` 插入）
- 載入券底圖，以 mm 設定實際券尺寸；底圖比例不符時會提醒並可一鍵修正
- 任意數量的文字欄位：內容範本（`{n}` = 編號，可加前後綴）、字型、字級（pt）、顏色、描邊、對齊、旋轉
- 拖曳定位（滑鼠／觸控皆可）、方向鍵微調、直接輸入 X/Y（mm）
- 編號：起訖、補零、排除含特定數字（如 4）、排除指定編號或區間
- 拼版：A4 / A3 / B4 / Letter、直橫向、欄列數、邊界、間距；放不下時自動縮放並明示比例；一鍵找出原尺寸下最多張的排法
- 疊切排序：整疊裁切後各疊依序疊起即為連號
- 頁緣裁切標記、券間虛線
- 成品尺寸可任意設定，附常用尺寸選單（名片、A6、明信片…）；即時顯示「這張紙一頁可放幾張」、紙張可印的最大尺寸、底圖解析度是否足夠
- 出血：選「自己印」或「送印刷廠」即可（自動 3 mm 出血、調整間距與裁切線）；編輯器畫出出血區、裁切線、安全區，附圖解說明；底圖可只做成品大小（自動補出血）或自帶出血
- 直接輸出 PDF（指定 dpi），或輸出單張 JPG 的 ZIP；有進度條、不會卡住畫面
- 「只印編號」套印模式
- 設定自動保存在瀏覽器；可匯出／匯入範本（含底圖）；復原／重做（Ctrl+Z）
- QR Code 欄位；防偽驗證碼（欄位內容寫 `{code}`），可匯出「編號 ↔ 驗證碼」對照表

### 抽獎紀錄（現場實體抽獎用）
- 設定獎項與名額、扣除未發出／作廢的編號
- 從箱中抽出實體券 → 輸入編號（或用 USB 條碼槍／相機掃 QR）→ 自動檢查：
  不在發出範圍、已作廢、已經中過、驗證碼不符（疑似偽造）都會被擋下
- 獨立投影視窗：主畫面登記，另一個視窗（拖到投影機）同步顯示得獎號碼與彩帶動畫；也可直接把本畫面全螢幕
- 名單模式下，得獎時一併顯示姓名等資料
- 投影用大字畫面（可全螢幕）、未到場作廢重抽、備用的電腦隨機抽
- 紀錄即時存在瀏覽器，重新整理不會遺失；可匯出 CSV、列印得獎名單

> 抽獎紀錄只存在「當時使用的那台電腦、那個瀏覽器」裡，活動當天請用同一台電腦，結束後記得匯出 CSV 備份。

## 列印提醒
列印 PDF 時請選「實際大小 / 100%」，不要選「符合頁面」，否則尺寸會跑掉。
