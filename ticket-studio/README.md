# 票券工作室

摸彩券、號碼牌、入場券、餐券、名牌／座位卡的編號印刷工具，附現場抽獎登記與投影。

純靜態網頁，放在任何網站空間（例如 GitHub Pages）就能用，不需要建置步驟（首次開啟需要網路載入 jsPDF / JSZip，圖片本身不會上傳）。程式使用 ES modules，必須透過 http(s) 開啟，直接雙擊 `index.html`（file://）無法執行。

## 功能
- 號碼排列可選「裁好疊起來就連號（疊切，推薦）」或「每頁依序排」並附說明；下載後的列印提醒會列出每一疊的號碼範圍
- 抽獎頁精簡：開始登記後獎項自動收成摘要（即時顯示已抽數量，可再按「編輯獎項」）；作廢號碼、防偽收進「其他設定」
- 省紙優先排版：自動排版以「一頁放最多張」為準（可縮小到 90%，例如摸彩券 A4 直印一頁 4 張）；第 3 步並列「省紙／原尺寸」兩種選擇並標出頁數差，選了會記住
- 簡易模式改成三步驟：① 放上券的圖片 ② 放號碼（從幾號到幾號，直接在預覽上拖曳）③ 下載列印；其餘設定都在「⚙ 更多設定」
- 上傳圖片（按鈕或直接拖進網頁）時，自動裁掉多出來的白邊、讓券的高度配合圖片比例，事後提示並可「復原」
- 介面精簡：頂部只留分頁與「⋯ 選單」（存檔、開檔、復原、重做、完整設定、恢復預設）；簡易模式下整頁預覽收在按鈕裡；號碼小工具列點了號碼才出現；還沒放圖時第 2、3 步會變淡提示順序
- 🤖 AI 畫背景（在「幫我做一張」裡）：用自己的 Google Gemini 或 OpenAI 金鑰，描述想要的背景（或點靈感），AI 只畫背景、文字與號碼由工具疊上（字不會錯）；保留最近幾張可挑選；金鑰只存在自己的瀏覽器、不會寫進「存成檔案」
- ✨ 沒有圖？幫我做一張：填活動名稱、日期地點、備註，選 6 種風格之一，可加存根／姓名欄／電話欄，直接產生 300 dpi 的券面圖片（支援出血），號碼自動放好
- 新手友善：選用途就套用、白話用詞、點選文字就出現「放大／縮小／顏色」小工具列、上傳圖片自動選黑字或白字、下載後提醒列印要選「實際大小」、提醒換電腦前先「存成檔案」
- 簡易模式（預設）：只顯示必要設定，換尺寸或紙張時自動排版；右上角「⚙ 完整設定」可展開所有進階選項
- 用途範本：摸彩券、號碼牌、入場券（QR＋防偽碼）、餐券／兌換券、名牌／座位卡，一鍵套用尺寸、欄位與拼版
- 資料來源：連續編號，或從 Excel 貼上／匯入 CSV 名單（每列印一張，欄位用 `{欄位名稱}` 插入）
- 載入券底圖，以 mm 設定實際券尺寸；底圖比例不符時會提醒並可一鍵修正
- 任意數量的文字欄位：內容範本（`{n}` = 編號，可加前後綴）、字型、字級（pt）、顏色、描邊、對齊、旋轉
- 拖曳定位（滑鼠／觸控皆可）、方向鍵微調、直接輸入 X/Y（mm）
- 編號：起訖、補零、排除含特定數字（如 4）、排除指定編號或區間
- 拼版：A4 / A3 / B4 / Letter、直橫向、欄列數、邊界、間距；放不下時自動縮放並明示比例；一鍵找出原尺寸下最多張的排法
- 疊切排序：整疊裁切後各疊依序疊起即為連號
- 頁緣裁切標記、券間虛線
- 成品尺寸可任意設定，附常用尺寸選單（名片、A6、明信片…）；即時顯示「這張紙一頁可放幾張」、紙張可印的最大尺寸、底圖解析度是否足夠
- 出血：選「自己印」或「送印刷廠」即可（自動 3 mm 出血、調整間距與裁切線）；編輯器畫出出血區、裁切線、安全區，附圖解說明；底圖可只做成品大小（自動補出血）或自帶出血
- 直接輸出 PDF（指定 dpi），或輸出單張 JPG 的 ZIP；有進度條、不會卡住畫面
- 「只印編號」套印模式
- 設定自動保存在瀏覽器；可匯出／匯入範本（含底圖）；復原／重做（Ctrl+Z）
- QR Code 欄位；防偽驗證碼（欄位內容寫 `{code}`），可匯出「編號 ↔ 驗證碼」對照表

### 抽獎（兩種抽法）
- **名單直接抽**：不用印券，把名單打進表格（或從 Excel 整塊貼上，可連欄名一起貼），按「抽出」由電腦隨機抽；可一次抽 1／3／5／10 位或這個獎剩下的全部，一位一位揭曉。同一個人不會中兩次，不在現場的人不會再被抽到；名單有重複會提醒。也可以一鍵帶入「印券設計」的名單
- **抽獎網址**：名單直接抽可以產生一個網址，同工點開就能抽（全螢幕、有「抽出」按鈕、支援簡報筆），也可以放進 PowerPoint（Web Viewer 增益集或超連結）。名單只在網址 # 後面，不會上傳
- **簡報筆**：按「下一頁」就抽出一位（主畫面或投影視窗都可以）
- 投影下方依獎項分類列出所有得獎者
- **抽印好的券**（下面幾項）：
- 設定獎項與名額、扣除未發出／作廢的編號
- 從箱中抽出實體券 → 輸入編號（或用 USB 條碼槍／相機掃 QR）→ 自動檢查：
  不在發出範圍、已作廢、已經中過、驗證碼不符（疑似偽造）都會被擋下
- 獨立投影視窗：主畫面登記，另一個視窗（拖到投影機）同步顯示得獎號碼與彩帶動畫；也可直接把本畫面全螢幕
- 名單模式下，得獎時一併顯示姓名等資料
- 投影用大字畫面（可全螢幕）、未到場作廢重抽、備用的電腦隨機抽
- 紀錄即時存在瀏覽器，重新整理不會遺失；可匯出 CSV、列印得獎名單

> 抽獎紀錄只存在「當時使用的那台電腦、那個瀏覽器」裡，活動當天請用同一台電腦，結束後記得匯出 CSV 備份。

## 列印提醒
列印 PDF 時請選「實際大小 / 100%」，不要選「符合頁面」，否則尺寸會跑掉。

## 程式結構

本機測試：在這個資料夾執行 `python3 -m http.server`，再開 `http://localhost:8000/`。

```
index.html        畫面（兩個分頁、對話框、圖示 sprite）
css/
  tokens.css      顏色與尺寸變數（所有顏色只在這裡定義）
  base.css        表單、按鈕、提示框
  shell.css       報頭、工作區（左工單＋右切割墊）、選單
  design.css      印券設計：三步驟、完整設定、量尺、整頁預覽
  draw.css        抽獎紀錄、得獎畫面、投影視窗
  dialogs.css     幫我做一張、列印提醒
js/
  main.js         啟動（投影視窗只跑 projector.js）
  constants.js    紙張、字型、用途範本、主題、localStorage 鍵名
  state.js        設定資料、復原／重做、存到瀏覽器
  numbers.js      編號、名單、驗證碼、欄位文字
  geometry.js     拼版幾何、自動排版
  render.js       欄位、底圖、QR 繪製（編輯器／預覽／PDF／ZIP 共用）
  background.js   底圖載入、白邊裁切、比例提醒
  editor.js       單張編輯器、拖曳、量尺、小工具列
  fields.js       文字欄位表單
  settings.js     設定綁定、範本、尺寸、出血、名單
  preview.js      整頁預覽
  info.js         排版摘要
  simple.js       三步驟面板
  grid.js         像 Excel 的名單格子（印券名單、抽獎名單共用）
  namegrid.js     印券設計的名單（勾「印」放到券上）
  refresh.js      設定改變後的整體重繪
  output.js       PDF、ZIP、驗證碼對照表
  files.js        存成檔案／開啟檔案／恢復預設
  generator.js    幫我做一張
  ai.js           AI 畫背景
  draw.js         抽獎（抽印好的券／名單直接抽）
  showlist.js     投影下方依獎項分類的得獎名單
  stagelink.js    抽獎網址的打包／解開
  stage.js        抽獎網址頁（stage.html）
  show.js         同步到投影視窗
  projector.js    投影視窗
  shell.js        分頁、選單、簡易／完整模式
  icons.js        SVG 圖示
  util.js         共用小工具
```

localStorage 鍵名與「存成檔案」的格式（`app: "ticket-studio", version: 2`）不可更動，否則使用者既有的資料會讀不到。
